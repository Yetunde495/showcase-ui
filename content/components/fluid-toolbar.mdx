```tsx
// Change Here
const SERVICES = [
  {
    id: "01",
    title: "Web Design",
    description: "Creating beautiful digital experiences.",
    image: "https://images.unsplash.com...",
  },
  // ...
];
```

```tsx
import FluidToolbar from "@/components/fluid-toolbar";

export default function Page() {
  return <FluidToolbar />;
}
```

## Features

- **Swipe Navigation**: Natural horizontal drag gestures on touch devices.
- **Optional Arrow Controls**: Enable arrow buttons for explicit navigation.
- **Overflow Awareness**: Edge blur indicates hidden items.
- **Directional Transitions**: Content animates based on navigation direction.
- **No Layout Shift**: Fixed-width tabs with adaptive expansion.
- **Auto-cycle**: Automatically rotates through tabs (pauses on hover).
